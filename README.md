Stone Paper Scissors Game 🎮

About the Project
This project is a browser-based Stone Paper Scissors game developed using HTML, CSS, and JavaScript. The application allows users to play the classic game against the computer, which generates a random choice each round.
The project demonstrates core web development concepts such as DOM manipulation, event handling, and game logic implementation using JavaScript.

Features
Interactive user interface
Computer generates random moves
Real-time game result display (Win / Lose / Draw)
Score tracking system
Simple and responsive design
Technologies Used
HTML – Page structure
CSS – Styling and layout design
JavaScript – Game logic and interactivity
How It Works
The player selects Stone, Paper, or Scissors.
The computer randomly chooses one option.
JavaScript compares both choices using game logic.
The result is displayed instantly on the screen.
The score updates after each round.
Learning Outcomes
Through this project I learned:
Implementing basic game logic
Using JavaScript for interactive web applications
Handling user events and DOM updates
Structuring a small front-end project
